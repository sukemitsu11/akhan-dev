# Портфолио Артема Хана

Русскоязычное портфолио на Astro и TypeScript. Статический HTML, обычный CSS, небольшой скрипт без клиентских фреймворков. База данных и переменные окружения не нужны. Основная рабочая папка: `C:\Coding\projects\akhan-dev`.

## Локальный запуск

Нужен Node.js 22.12 или новее. Рекомендуется Node.js 24 LTS.

```sh
cd C:\Coding\projects\akhan-dev
npm ci
npm run dev
```

Откройте адрес, который напечатает Astro (обычно http://127.0.0.1:4321).

```sh
npm run check   # Проверка TypeScript и Astro
npm run build   # Проверка типов и production-сборка в dist/
npm run preview # Просмотр production-сборки
```

Если среда запрещает Astro создавать настройки телеметрии, задайте `ASTRO_TELEMETRY_DISABLED=1` перед командой. В PowerShell: `$env:ASTRO_TELEMETRY_DISABLED='1'`.

## Где менять данные

`src/config.ts` содержит имя, роль, город, Telegram, GitHub, адрес сайта, ссылку на исходники и доступность для проектов. Объект `content` в этом же файле содержит все тексты о себе, подписи интерфейса, навигацию и категории стека. Кнопки обсуждения в первом экране и тарифах используют единый `siteConfig.telegram`.

Ваши значения уже внесены: **Артем Хан**, Ростов-на-Дону, `https://t.me/akhan_dev`, `https://akhan.dev`. При смене домена обновите `siteConfig.url`: из него автоматически формируются canonical, Open Graph URL, robots.txt, sitemap.xml и JSON-LD Person.

В `public/og.png` находится готовая картинка для социальных сетей 1200 × 630. При смене имени/роли обновите и изображение. Значок сайта: `public/favicon.svg`. Портрет: `src/assets/profile/artem-khan.png`; Astro создаёт оптимизированные WebP и адаптивные размеры. Кадрирование и приглушение цвета настраиваются в `.profile-portrait` в CSS, исходная фотография сохранена.

## Как добавлять проекты

Отредактируйте массив `projects` в `src/data/projects.ts`. Сейчас в нём четыре демонстрационных проекта: «Комната», «Контур», «Грань» и «Чистый лист». В превью заменены названия компаний, города, адреса, телефоны и почта. Метка «Демонстрационный проект» есть у каждой работы и на отдельной странице. Исходные сайты компаний не изменялись. Кнопок исходного кода у проектов нет.

Добавьте длинное изображение сайта в `src/assets/projects/` и импортируйте его в data-файле. На главной показываются первые четыре работы. Начиная с пятой автоматически появляется кнопка «Все работы», ведущая на `/projects/`. Эта страница всегда содержит полный массив проектов.

Поле `demo` ведёт на полноценный сайт. Четыре готовых концепта находятся в `public/demos/`: там лежат их HTML, CSS, JavaScript и изображения. Адреса ресурсов и переходы внутри демо изолированы по папкам. Формы демонстрационные, данные и фотографии остаются в браузере. Подпись внизу каждой HTML-страницы содержит ссылку на главную портфолио; общие стили и поведение находятся в `public/demos/concept.css` и `concept.js`. Старые адреса `/projects/<id>/` перенаправляют к демо.

Для новой работы разместите готовый статический сайт в `public/demos/my-project/`, проверьте локальные пути и добавьте аналогичную подпись. Можно также указать внешний URL в `demo`.

```ts
import screenshot from '../assets/projects/my-project.png';

{
  id: 'my-project',
  name: 'Название проекта',
  category: 'Веб-приложение',
  description: 'Что делает проект и какую задачу решает.',
  technologies: ['Astro', 'TypeScript'],
  image: screenshot,
  previewLabel: 'my-project.example',
  demo: '/demos/my-project/index.html',
  year: '2026',
  scope: ['Каталог услуг', 'Галерея работ', 'Форма заявки'],
}
```

Поле `id` должно быть уникальным. Нумерация списка формируется автоматически.

Для скролла превью изображение должно быть выше, чем область браузерной рамки. Сейчас используются изображения 1440 × 3600. При наведении картинка плавно смещается до нижнего края; при уходе курсора возвращается наверх. Размеры пересчитываются через ResizeObserver без покадрового JavaScript. На сенсорных устройствах есть кнопка «Пролистать превью». При reduced motion автоматическая прокрутка отключена. Ссылки, кнопки и навигация не содержат стрелок.

## Возможности

Основной макет открытый: без декоративных рамок и подложек у текстовых блоков, услуг, этапов и контактов. Крупные разделы отделены тонкими горизонтальными линиями, соседние колонки — короткими вертикальными. На телефоне разделители становятся короткими горизонтальными штрихами. Фоновый растр приглушён; вторичный текст и подписи усилены по контрасту.

Раздел «Как работаю» объединяет этапы проекта и состав разработки. Его заголовок и содержание редактируются в `src/config.ts`: объекты `content.development` и `content.workflow`. Разметка — `src/components/Development.astro` и вложенный `Workflow.astro`. Стоимость вынесена в `Pricing.astro` с данными `content.pricing`. На широком экране пять услуг стоят в одном ряду; на планшете и телефоне сетка перестраивается для чтения. Цена админки указана как дополнение к разработке сайта; домен и хостинг оплачиваются отдельно.

- Светлая и тёмная темы; первая загрузка учитывает системную тему до отрисовки страницы. Выбор сохраняется в localStorage и синхронизируется между вкладками.
- Палитра команд: Ctrl+K / Cmd+K или кнопка в шапке. Поиск, Tab, клавиши вверх/вниз, Enter, Escape. Нативный диалог удерживает фокус и возвращает его после закрытия.
- Переход в личный Telegram из первого экрана, тарифов, контактов и палитры команд.
- Закреплённая шапка с индикатором активного раздела. Якоря учитывают высоту шапки на компьютере и телефоне.
- Последовательное появление блоков, отклик кнопок и короткий глитч логотипа раз в 24 секунды. Фон — глубокий графит `#151518`, мелкое зерно и меняющиеся растровые облака из квадратных точек по мотивам nahiyan.codes. Компонент `src/components/AmbientBackground.astro` использует Canvas 2D без библиотек, не более 12 отрисовок в секунду и разрешение в CSS-пикселях. В скрытой вкладке обновления останавливаются; `prefers-reduced-motion` оставляет статичный рисунок. Светлая тема поддерживается.
- Четыре этапа работы с текстами в `content.workflow` (`src/config.ts`), разметка — `src/components/Workflow.astro`.
- Крупная кнопка Telegram в контактах использует тот же адрес из `siteConfig.telegram`, что и остальные кнопки обсуждения.
- Семантическая разметка, ссылка пропуска навигации, видимый фокус, доступные подписи, адаптивные размеры.
- Основной контент и навигация доступны без JavaScript. Кнопки, зависящие от JavaScript, появляются после инициализации.
- SEO: метатеги, canonical, Open Graph, Twitter Cards, favicon, robots.txt, sitemap.xml со страницами проектов, JSON-LD Person, страница 404.

## Деплой на Vercel

1. Замените персональные данные, адрес сайта и ссылки проектов. Выполните `npm run build`.
2. Добавьте исходники проекта в свой Git-репозиторий, без `node_modules`, `dist`, `.astro`.
3. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
4. Если в репозитории есть другие папки, укажите **Root Directory**: `coding/projects/akhan-dev`. Если репозиторий содержит только этот проект, оставьте корень.
5. **Framework Preset**: Astro. **Build Command**: `npm run build`. **Output Directory**: `dist`. Выберите Node.js 24.x.
6. Нажмите **Deploy**. После получения домена запишите его в `siteConfig.url` и отправьте изменение в репозиторий для новой сборки.

Проект полностью статический; серверный адаптер `@astrojs/vercel` не требуется. `vercel.json` уже содержит настройки сборки и базовые HTTP-заголовки.

## Дизайн

Референс по текстовой подаче, контрасту и фактуре: https://nahiyan.codes/. Собственная композиция, палитра и навигация. Применены Taste Skill, kill-ai-slop и design-motion-principles. На компьютере используется широкая композиция с левым выравниванием и максимальной шириной 1480 px. Вверху текст и фотография, ниже галерея проектов в два столбца. На телефоне галерея становится одноколоночной. Шрифт Onest размещён локально и поддерживает кириллицу; подписи моноширинные. Обе темы, медный акцент, статическое зерно. Тяжёлых UI-компонентов и библиотек анимации нет.

Оценки Lighthouse зависят от хостинга, устройства и содержимого после ваших изменений. Сам факт успешной сборки не является измерением Performance, Accessibility или SEO.
